================================================================================
                            USAGE PATTERNS
================================================================================

1. CLI WITH YAML (Recommended)
   └─ yoloflow config template my_config.yaml
   └─ yoloflow config validate my_config.yaml
   └─ yoloflow train --config my_config.yaml

2. PYTHON API
   └─ config = TrainingConfig.from_yaml("config.yaml")
   └─ orchestrator = TrainingOrchestrator(config)
   └─ results = orchestrator.run()

3. PROGRAMMATIC
   └─ config = TrainingConfig(model=ModelConfig(...), ...)
   └─ orchestrator = TrainingOrchestrator(config)
   └─ results = orchestrator.run()

4. LEGACY CLI (Backward Compatible)
   └─ python train_legacy.py --model yolo26n.pt --data dataset.yaml

================================================================================
                           QUICK START
================================================================================

# 1. Generate configuration template
yoloflow config template my_config.yaml

# 2. Edit configuration (set your model, dataset, hyperparameters)
vim my_config.yaml

# 3. Validate configuration
yoloflow config validate my_config.yaml

# 4. Start training
yoloflow train --config my_config.yaml

# 5. Results saved to: runs/train/[experiment_name]/
